# پژوهش و منابع

این بخش برای مرور ادبیات، نظریه‌های مرتبط، منابع علمی و یادداشت‌های پژوهشی است.

## استاندارد ثبت منبع

تا حد امکان این اطلاعات ثبت شود:
- نویسنده
- عنوان
- ناشر یا نشریه
- سال انتشار
- DOI یا نشانی پایدار
- تاریخ دسترسی (برای منابع برخط)
- بخش یا صفحهٔ مورد استفاده
- خلاصهٔ مرتبط با نظریه
- ارزیابی محدودیت‌ها و نقدهای منبع

وجود یک منبع در این پوشه به‌معنای تأیید دیدگاه آن یا پذیرش آن در نظریه نیست.
