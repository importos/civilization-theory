# نظریه تمدن | Civilization Theory

پروژه‌ای پژوهشی و مشارکتی برای صورت‌بندی، نقد و توسعهٔ «نظریه تمدن».

**بنیان‌گذار و نگه‌دارندهٔ چارچوب نظری:** `importos`  
**زبان اصلی:** فارسی  
**وضعیت مخزن:** عمومی (Public) — در حال توسعه

## هدف پروژه

این مخزن فضای مستند و نسخه‌بندی‌شده‌ای برای توسعهٔ نظریه تمدن است؛ نظریه‌ای که می‌کوشد مفاهیم، ساختارهای اجتماعی، مسائل جمعی، جریان منابع و سازوکارهای تحول جوامع را به‌شکلی منسجم بررسی کند.

این پروژه صرفاً محل انتشار یک متن نهایی نیست. تعریف‌ها، فرضیه‌ها، مدل‌ها، نقدها و تغییرات نظریه باید قابل ردیابی و بررسی باشند.

## اصول راهنما

1. **شفافیت مفهومی:** هر مفهوم باید تعریف روشن، مرز کاربرد و نسبت خود با مفاهیم دیگر را داشته باشد.
2. **تفکیک سطح اعتبار:** ایدهٔ خام، فرضیهٔ پژوهشی و گزارهٔ پذیرفته‌شده نباید با هم اشتباه شوند.
3. **نقدپذیری:** هیچ ادعایی صرفاً به دلیل تعلق به بنیان‌گذار یا مشارکت‌کننده مصون از نقد نیست.
4. **استدلال‌محوری:** پیشنهادها باید همراه با دلیل، مثال، منبع یا پیامد قابل بررسی باشند.
5. **ردیابی تغییرات:** تغییرات مفهومی و نظری باید در Git ثبت و در صورت لزوم در CHANGELOG توضیح داده شوند.
6. **تکثر دیدگاه‌ها:** نقد دیدگاه‌ها آزاد است؛ بی‌احترامی و حمله به اشخاص پذیرفته نیست.

## ساختار مخزن

- `docs/` — اسناد اصلی و چارچوب نظری
- `research/` — مطالعات، منابع و نظریه‌های مرتبط
- `publications/` — پیش‌نویس مقاله‌ها و کتاب
- `discussions/` — موضوعات و پرسش‌های باز
- `.github/` — الگوهای مشارکت و گردش‌کار GitHub

## وضعیت اعتبار محتوا

- **Accepted:** بخشی از چارچوب رسمی فعلی پروژه؛ قابل بازنگری است.
- **Proposed:** پیشنهاد در حال بررسی؛ هنوز جزو چارچوب پذیرفته‌شده نیست.
- **Research:** یادداشت پژوهشی، فرضیه یا بررسی منابع؛ به‌خودی‌خود موضع رسمی پروژه نیست.

وضعیت هر سند باید در ابتدای آن مشخص شود.

## مشارکت

برای پیشنهاد تغییر ابتدا `CONTRIBUTING.md` را بخوانید. گفت‌وگوهای مفهومی در GitHub Discussions و گزارش خطاها، ابهام‌ها و پیشنهادهای مشخص در Issues انجام می‌شود. تغییر متن‌ها از طریق Pull Request ارائه می‌شود.

پذیرش مشارکت به معنی پذیرش خودکار دیدگاه پیشنهادی به‌عنوان موضع نظریه نیست.

## حاکمیت پروژه

پروژه در مرحلهٔ فعلی با **مدل بنیان‌گذارمحور** اداره می‌شود:

- بنیان‌گذار مسئول حفظ انسجام چارچوب، تعیین اولویت‌ها و تصمیم نهایی دربارهٔ ادغام تغییرات در شاخهٔ `main` است.
- مشارکت‌کنندگان می‌توانند آزادانه نقد، پیشنهاد و Pull Request ارائه کنند.
- تصمیم نهایی باید تا حد امکان با توضیح روشن و مستدل ثبت شود.
- این مدل می‌تواند در آینده با انتشار نسخهٔ جدید منشور بازنگری شود.

جزئیات در `GOVERNANCE.md` آمده است.

## وضعیت مجوز

مخزن عمومی است، اما مجوز استفاده و بازنشر هنوز تعیین نشده است. تا زمان افزودن مجوز صریح، انتشار عمومی به‌معنای اعطای مجوز آزاد برای استفاده، اقتباس یا بازنشر نیست. جزئیات در `LICENSE-DECISION.md` آمده است.
