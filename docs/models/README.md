# مدل‌ها

این پوشه برای مدل‌های مفهومی، علّی، ساختاری یا تحلیلی نظریه است.

هر مدل باید شامل این موارد باشد:

- مسئله‌ای که مدل برای توضیح آن ساخته شده
- مفروضات و دامنهٔ اعتبار
- اجزا و روابط میان اجزا
- تعریف متغیرها یا مفاهیم
- نمودار یا صورت‌بندی، در صورت نیاز
- مثال کاربردی
- محدودیت‌ها و تبیین‌های رقیب
- وضعیت اعتبار و تاریخ بازنگری
