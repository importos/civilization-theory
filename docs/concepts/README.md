# واژگان و مفاهیم نظریه

این پوشه مرجع تعریف مفاهیم نظریه است. هر مفهوم مهم باید ترجیحاً سند مستقل داشته باشد.

## وضعیت مفاهیم

- `Research`: یادداشت اکتشافی یا مفهوم در حال مطالعه
- `Proposed`: تعریف پیشنهادی که هنوز بررسی و تأیید نهایی نشده
- `Accepted`: تعریف مرجع در نسخهٔ جاری نظریه

## الگوی نام‌گذاری

نام فایل‌ها کوتاه، انگلیسی، با حروف کوچک و خط تیره باشد؛ عنوان و محتوای سند می‌تواند فارسی باشد.

## الگوی پیشنهادی سند مفهوم

```markdown
# نام مفهوم

**شناسه:** C-XXX
**وضعیت:** Research / Proposed / Accepted
**نسخه:** 0.1

## تعریف کوتاه

## تعریف تفصیلی

## دامنه و مرزها

## مفاهیم مرتبط و پیش‌نیاز

## مثال‌ها

## مثال نقض و محدودیت‌ها

## نقش در نظریه

## پرسش‌های باز

## منابع
```
